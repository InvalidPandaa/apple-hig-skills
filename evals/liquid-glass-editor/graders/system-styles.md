PASS if selection or primary-action emphasis uses the app accent/tint (for example .tint, .accentColor, .glassProminent or a system control style) rather than a hard-coded color like .blue, AND the tool picker uses a system component or button style (for example a bottom toolbar, a Picker/segmented control, or .buttonStyle(.glass)) rather than .buttonStyle(.plain) combined with a manual .glassEffect.
FAIL otherwise.
